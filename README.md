Simple implementation of an LSTM neural network, using the existing weather database to forecast changes in solar irradiance

Try playing with the number of epochs and the random seed to improve prediction results



Versions used:

pandas - 2.0.3

numpy - 1.25.2

matplotlib - 3.7.2

statsmodels - 0.14.6

scikit-learn - 1.8.0

tensorflow - 2.16.1

seaborn - 0.13.2





\*Note: Change the CSV directory in line 6 to the local directory of your CSV file
